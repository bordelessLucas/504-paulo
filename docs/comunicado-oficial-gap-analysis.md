## Modelo oficial (resumo)

### Escala 0 a 3

| Nota | Significado |
|------|-------------|
| 0 | X Crítico — risco operacional |
| 1 | Desenvolvimento — falhas frequentes |
| 2 | Boa Performance — atende padrões |
| 3 | Excepcional — referência |

### 12 seções IMA

`IMA = (GO×3 + SB×3 + LG + PE + PR + MA + TR + SM + RH + FA + PG + IN) / 16`

### Ciclos

| Código | Nome | Quem avalia |
|--------|------|-------------|
| Quinzenal | Bordo | Supervisor de bordo (SB) |
| Semestral | Gestores | Gestores de base + Gerente (GO) |
| Anual | Estratégica | RH / Gerente / CEO |
